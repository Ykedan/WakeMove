# WakeMove 醒动官网

WakeMove 醒动的产品官网，使用 React、Next.js 与 vinext 构建。

## 本地开发

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 构建与测试

```bash
npm run build
npm test
```

## 页面内容

- Android APK 下载入口
- 唤醒流程与核心功能说明
- WakeMove 真实 App 界面
- 本地动作识别与离线语音能力说明

APK 由 [WakeMove GitHub Releases](https://github.com/Ykedan/WakeMove/releases) 提供。
