# WakeMove 晨光仪表盘界面改版设计

## 目标

把 Android 端当前偏原型化的闹钟首页和新增/编辑闹钟页，升级为适合后续上架的“温暖晨光感”界面。改版只调整视觉呈现与输入控件，不改变闹钟创建、启停、调度、挑战、保存或删除的业务规则。

## 范围

本阶段包含：

- 闹钟首页
- 新增闹钟页
- 编辑闹钟页
- 首页可见的底部导航图标与选中样式
- 上述页面共用的颜色、圆角、排版和组件样式

本阶段不包含：

- 历史、健康检查、设置、引导和响铃挑战页面的整体改版
- 闹钟调度、权限、摄像头识别、语音识别和稍后提醒逻辑变更
- 深色模式
- 新的插画图片或在线资源

## 视觉方向

采用“晨光仪表盘”方案：

- 奶油白作为页面背景
- 日出橙作为主操作色
- 暖黄色到橙色的柔和渐变用于重点卡片
- 深棕黑作为主要文字颜色
- 白色卡片配合轻微阴影形成层次
- 圆角保持柔和、现代，但不做儿童化处理
- 动效只使用轻微按压、选择和切换反馈

界面装饰优先使用 Compose 原生图形、图标和渐变，不依赖网络图片。

## 闹钟首页

### 顶部区域

- 主标题显示“早上好”。
- 副标题显示“让今天从真正醒来开始”。
- 标题字号比当前版本更克制，避免与闹钟时间争夺视觉焦点。
- 右侧设置入口改为圆形图标按钮，不再显示橙色“设置”文字。

### 下一次唤醒卡片

- 顶部主卡片使用暖黄色到日出橙的渐变。
- 从所有已启用闹钟中计算真正最近的一次发生时间。
- 展示闹钟时间、名称、重复日期和挑战方式。
- 卡片整体可点击，点击后进入对应闹钟编辑页。
- 如果存在闹钟但全部停用，展示“开启一个闹钟，迎接新的早晨”。
- 如果完全没有闹钟，不展示空的下一次唤醒卡片，改用专用空状态。

### 闹钟列表

- 使用“我的闹钟”作为分区标题，并显示闹钟总数。
- 每个闹钟使用白色圆角卡片。
- 时间是卡片的第一视觉层级。
- 名称与重复日期作为辅助信息。
- 挑战方式使用浅橙色标签展示。
- 右侧保留启用开关。
- 点击卡片进入编辑页。
- 停用状态降低文字和标签强调度，但仍保持足够可读性。

### 新增入口

- 移除右下角大型圆形悬浮加号。
- 使用宽圆角按钮“＋ 添加新闹钟”。
- 有闹钟时放在列表末尾；无闹钟时放在空状态内容中。
- 保留现有 `add_alarm` 测试标记和防重复提交行为。

### 空状态

- 使用 Compose 原生形状组成简洁日出图形。
- 标题显示“还没有闹钟”。
- 辅助文案说明动作或语音挑战的价值。
- 提供“设置第一个闹钟”主按钮。
- 内容在可用空间内视觉居中，避免当前版本的大面积无意义留白。

### 底部导航

- 将“钟、史、检”文字占位符替换为标准线性图标。
- 标签仍显示“闹钟”“历史”“健康检查”。
- 当前选中项使用浅橙色胶囊背景。
- 导航行为和目的地保持不变。

## 新增与编辑闹钟页

### 顶部栏

- 左侧使用返回箭头。
- 标题显示“新建闹钟”或“编辑闹钟”。
- 不增加右侧操作按钮。
- 返回行为和提交期间的禁用规则保持不变。

### 时间区域

- 使用暖黄色渐变卡片承载时间。
- 时间以大号数字居中显示。
- 时间仍写入现有 `timeText` 状态并通过现有解析规则验证。
- 保留 `alarm_time` 测试标记。

### 闹钟名称

- 使用独立的简洁输入框。
- 提示示例为“例如：上班、晨跑、早课”。
- 名称仍为可选字段。

### 重复日期

- 周一至周日显示为七个尺寸一致的圆形按钮。
- 选中状态使用日出橙填充，未选中状态使用浅米色。
- 每个按钮保持至少 48 dp 点击区域。
- 保留 `weekday_<DAY>` 测试标记、选中语义和复选角色。

### 起床挑战

- 四种挑战显示为带图标、名称和简短说明的选择卡片。
- 选中项显示橙色边框、浅橙背景与对勾。
- 挑战类型与说明：
  - 深蹲：完成指定次数后关闭
  - 开合跳：完成指定次数后关闭
  - 双手举高：完成指定次数后关闭
  - 朗读短语：正确朗读指定短语后关闭
- 保留 `challenge_<TYPE>` 测试标记与单选语义。

### 目标次数

- 非语音挑战使用减号、当前数值、加号组成的步进器。
- 加减操作继续调用现有 `onTargetCountChange(Int)`。
- 数值必须遵守现有状态与保存校验规则。
- 保留 `target_count` 测试标记，确保既有自动化测试可以迁移而不丢失覆盖。
- 语音挑战不显示次数控件。

### 保存、删除与异常提示

- 保存按钮使用底部醒目的宽圆角样式，文字为“保存闹钟”。
- 保存期间继续显示进度并阻止重复提交。
- 保留 `save_alarm` 与 `submission_progress` 测试标记。
- 编辑已有闹钟时，在内容底部显示低强调红色“删除闹钟”入口。
- 删除仍需二次确认，并保留 `confirm_delete` 测试标记。
- 健康、调度和提交异常统一显示为浅红色提示卡。

## 可访问性与适配

- 所有主要操作保持至少 48 dp 点击区域。
- 颜色不能作为选中状态的唯一表达；挑战选中项还要使用边框和对勾。
- 文本与背景保持足够对比度。
- 页面适配当前最低 Android 版本和 Compose 技术栈。
- 编辑页继续支持垂直滚动，避免小屏设备内容被截断。
- 不删除或随意重命名现有测试标记。

## 测试与验收

- 首页在无闹钟、存在启用闹钟、全部停用和操作失败四种状态下均可正确呈现。
- 下一次唤醒卡片选择真正最近的已启用闹钟。
- 点击设置、闹钟卡片、新增按钮和底部导航仍到达原有目的地。
- 编辑页的时间、名称、日期、挑战和次数操作仍更新原有状态。
- 保存、删除、加载和错误状态仍符合现有行为。
- Compose 单元/界面测试、Android instrumentation 测试、lint、debug 和 release 构建全部通过。
- 在模拟器中人工检查首页空状态、至少两个闹钟的列表状态、新建页和编辑页，并保存截图用于视觉比对。
