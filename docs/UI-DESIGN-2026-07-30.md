# WakeMove 1.2 前端视觉系统

更新时间：2026-07-30

## 设计目标

WakeMove 面向容易顺手关掉闹钟、需要被真正叫醒的 Android 用户。界面的第一任务
不是“展示很多功能”，而是让用户一眼看清下一次闹钟，并在响铃时立即找到挑战入口。

## 参考与取舍

- Mobbin 的真实移动端 onboarding 和 time picker 样本：学习信息优先级、底部主操作和
  首次使用流程，不复制具体页面。
- Dribbble / Behance 的睡眠与闹钟作品：学习夜间界面的低眩光层次、巨大时间数字和
  声音可视化，但避免常见的霓虹紫渐变、玻璃拟态和装饰性图表。
- Material 3 Expressive：用颜色、形状、尺寸和容器关系引导注意力；关键按钮明显大于
  次要操作，同时保留 Android 用户熟悉的导航和控件行为。

## “蓝调破晓”设计语言

### 颜色

- Night Ink：`#0D1324`，响铃页与核心主卡
- Wake Blue：`#4056C7`，品牌、导航和普通主操作
- Dawn Coral：`#FF7458`，只用于需要立即行动的唤醒动作
- Sky：`#BCD0FF`，深色背景上的辅助信息
- Cloud：`#F6F7FB`，普通页面背景
- Mist：`#E9EDF7`，分组和未选中状态

### 字体

- 时间和核心标题：系统 Sans Serif ExtraBold，大字号、略收紧字距
- 页面标题：系统 Sans Serif Bold
- 正文与说明：系统 Sans Serif Regular / Medium

不引入联网字体，保证所有 Android 设备离线显示稳定。

### 布局

- 首次进入：品牌眉题 → 唤醒轨道主视觉 → 核心价值 → 三项能力 → 单一主按钮
- 首页：随时间变化的问候、副标题与日期 → 下一次唤醒深色主卡 → 闹钟列表 →
  浮动式底部导航
- 编辑页：深色时间轮 → 标签 → 重复 → 声音与震动 → 挑战 → 固定保存
- 响铃页：状态 → 唤醒轨道与时间 → 唤醒任务 → 开始挑战 → 贪睡 → 紧急停止

### 识别元素

“唤醒轨道”由冷色圆弧和一枚穿过夜色的珊瑚色唤醒点组成。它只出现在首次进入、
空状态和响铃等关键时刻，避免每张卡片都堆叠装饰。

## 可用性约束

- 普通页面主按钮保持至少 56dp 高；响铃主按钮为 60dp。
- 危险的紧急停止不与主挑战按钮争夺视觉焦点，仍保留按住 10 秒保护。
- 首次权限说明和铃声选择在小屏上可滚动。
- 深色响铃界面使用低眩光蓝黑背景，重要文字保持高对比。
- 现有测试标签、无障碍语义和关键中文操作名称保持稳定。
